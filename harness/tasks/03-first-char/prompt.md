1. `fn firstChar(s: string): string | null` — the first character of `s` as a one-character string, or `null` when `s` is empty.
2. `fn firstCharUpper(s: string): string` — the first character of `s` uppercased, or the empty string `""` when `s` is empty. It must use `firstChar`.
